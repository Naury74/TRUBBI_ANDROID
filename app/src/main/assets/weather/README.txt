날씨 Lottie 애니메이션 배경
==========================

이 폴더에 무료 Lottie 애니메이션(JSON)을 아래 파일명으로 넣으면, 메인 화면 배경이
해당 애니메이션으로 재생됩니다. 없는 파일은 자동으로 기존 일러스트 배경으로 대체됩니다.

필요한 파일명 (조건 _ 주간/야간):
  clear_day.json      clear_night.json
  clouds_day.json     clouds_night.json
  rain_day.json       rain_night.json
  snow_day.json       snow_night.json
  thunder_day.json    thunder_night.json
  fog_day.json        fog_night.json

추천 무료 소스 (LottieFiles, 라이선스 확인 후 사용):
  https://lottiefiles.com/featured  에서 "weather", "sunny", "rain", "snow",
  "cloudy", "thunderstorm", "night" 등으로 검색 → JSON(Lottie) 다운로드 후 위 이름으로 저장.

팁:
  - 전체 화면을 채우므로 배경이 단순/은은한 풀배경형 애니메이션이 좋습니다.
  - 너무 화려하면 위에 글자 가독성이 떨어지니, 위에 어두운 스크림(이미 적용됨)과 어울리는
    것을 고르세요.
  - 주간/야간 구분이 어려우면 같은 파일을 day/night 양쪽에 복사해도 됩니다.
